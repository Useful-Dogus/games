# 프로젝트 개요

> 이 문서는 `docs/platform.md` §1–2의 에이전트용 요약본입니다. 전체 명세는 `docs/platform.md`를 참조하세요.

## 기본 정보

- **프로젝트명**: Dogus Games Platform
- **팀**: dogus
- **목표**: 웹 브라우저에서 바로 플레이할 수 있는 캐주얼 게임 플랫폼 구축. 별도 앱 설치 없이 URL 접근만으로 게임 플레이 가능.

## 핵심 개념

- **허브 사이트** (`dogusgames.com`): 게임 목록 메인 페이지. 코드베이스상 `apps/web`.
- **게임 앱**: 개별 게임을 독립 실행하는 웹 앱. 코드베이스상 `apps/<slug>`. 초기에는 플레이스홀더 형태.
- **서브패스 노출**: 허브 사이트의 Next.js rewrites를 통해 모든 게임이 `dogusgames.com/<slug>`처럼 보임. 실제로는 각 앱이 독립 배포.

## 이해관계자

| 이해관계자 | 역할 | 주요 관심사 |
|---|---|---|
| dogus 팀 (개발자) | 플랫폼 및 게임 개발·운영 | 개발 생산성, 코드 재사용, 배포 자동화 |
| 최종 사용자 (플레이어) | 게임 플레이 | 빠른 로딩, 쾌적한 UX, 안정성 |
| 게임 디자이너 | 게임 콘텐츠 기획 | 게임 추가 용이성, 플레이스홀더 구조 파악 |

## 현재 단계 제약 (초기 MVP)

- 백엔드 API, 사용자 인증, 점수 저장 기능 **없음**.
- 게임 앱은 플레이스홀더 형태. 실제 게임 엔진 도입은 이후 스프린트에서 결정.
- 배포는 Vercel 무료 플랜 기준.
- 개발 환경: Node.js 20 LTS 이상, pnpm 9 이상.
- 도메인 `dogusgames.com`은 팀이 확보하였거나 확보 예정.

## 사용자 특성

- 별도 로그인 없이 게임에 바로 접근.
- 모바일(375px) 및 데스크탑(1440px) 브라우저 모두 사용.
- 짧은 세션(5~15분)의 캐주얼 플레이 패턴.
