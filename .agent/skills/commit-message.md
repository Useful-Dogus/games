# Skill: Commit Message

> Full convention and branch/PR rules: `skills/git-workflow.md`

## Quick Reference

Format: `<emoji> [scope:] <subject>`

Emoji mapping:

- ✨ feature / 💄 UI / 🐛 bug fix / ♻️ refactor / 🔧 config / 📝 docs
- ➕ add dep / ➖ remove dep / 🔥 delete / 🏗️ structural change

Output rule: always present suggestions in a Markdown fenced code block.
