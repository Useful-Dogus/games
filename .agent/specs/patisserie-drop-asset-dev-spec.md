## 1. Art Direction

### Concept
Suika-style 낙하 합체 퍼즐 + 프렌치 파티스리 세계관. 작은 마카롱이 떨어져서 거대한 크로캉부슈로 성장하는 만족감이 핵심.

### Style
| 항목 | 방향 |
|---|---|
| 스타일 | 2D 플랫 일러스트 + 소프트 섀도, 약간의 hand-drawn 질감 |
| 팔레트 | 크림, 카라멜, 로즈 핑크, 초콜릿 브라운, 피스타치오, 베리 퍼플 |
| 레퍼런스 무드 | Neko Atsume × 프렌치 그림책 × 고급 파티스리 쇼케이스 |
| NOT | 3D 렌더, 과도한 chibi, 네온, 사실적 식품 사진 |

### 티어 별 개성
| 티어 | 레벨 | 방향 |
|---|---|---|
| Drop tier | Lv1–6 | 작고 정교한 보석 같은 파티스리 |
| Rare tier | Lv7–9 | 특별한 날의 쇼케이스 아이템 |
| Epic tier | Lv10–11 | "와" 소리 나오는 그랑 앙트르메 |

## 2. 스프라이트 스펙 — 11종

### 2.1 공통 기술 규칙

```
포맷     PNG-32 (RGBA, 투명 배경)
앵커     Center (0.5, 0.5)
형태     정사각형 PNG — 아트워크는 내접원 안에만 그릴 것
마스킹   Phaser가 physics radius로 원형 클리핑 처리 → PNG에 별도 원형 크롭 하지 말 것
소스     AI 또는 PSD, 1024×1024
네이밍   item-lv01.png … item-lv11.png (제로패딩 2자리)
납품     2× 기준 (retina 대응). 1× fallback도 @1x/ 폴더에 별도 제공
```

> **광원**: 좌상단 고정. 모든 아이템 동일 적용.
> **아웃라인**: 흰색 반투명 테두리 2–3px — 겹쳤을 때 개체 구분용.

### 2.3 아이템별 아트 노트

**Lv01 — 마카롱**
- 25° 내려다보기 각도 → 두 쿠키 디스크 + 크림 필링 단면이 모두 보이도록
- 파우더 슈가 질감 표면
- (optional) 컬러 variant 2종: 로즈 핑크 / 민트 (향후 테마 전환 대비)

**Lv02 — 사블레 쿠키**
- 원형 쇼트브레드, 꽃 스탬프 or 격자 엠보싱
- 72px에서도 엠보싱 패턴 식별 가능해야 함

**Lv03 — 슈크림**
- 돔 형태 상단 + 카라멜 drizzle 한쪽
- 하단 봉합선에 크림이 살짝 삐져나온 디테일 → 캐릭터 감

**Lv04 — 마들렌**
- 조개 릿지 (ribbing) 탑뷰 중앙 배치
- 클래식 bosse (봉우리) 표현
- 레몬 제스트 → 옐로그린 테두리 하이라이트

**Lv05 — 에클레어**
- 타원형, 원 프레임 안에 대각선 또는 수평 배치
- 다크 초콜릿 가나슈 상단 + 골드 브러시스트로크 or 커피 글레이즈 변형
- 110px 축소 시에도 형태 식별 가능 여부 확인 필수

**Lv06 — 쿠앵아망**
- 러스틱한 원형 파티스리, 25° 탑뷰
- 동심원 플레이키 레이어 + 앰버 카라멜 패치
- 완벽한 원이 아닌 약간의 유기적 울퉁불퉁함 권장 (authentic 느낌)

**Lv07 — 과일 타르트** ← 첫 번째 "와" 포인트
- 원형 타르트, 커스터드 베이스 위 과일 5–7종 방사형 배치
- 딸기 / 블루베리 / 라즈베리 / 키위 조합
- 과일 위 젤리 글레이즈 반사광 필수 → "먹음직스럽다" 반응 유도

**Lv08 — 샤를로트 로열** ← 비주얼 하이라이트
- 25° 탑뷰 돔 케이크
- 표면에 스위스 롤 슬라이스 스파이럴 패턴 (핑크/화이트 소용돌이)
- SNS에 올리고 싶을 만큼 아름다워야 함

**Lv09 — 뷔슈 드 노엘**
- 통나무 케이크 정면 단면 → 원형 크로스섹션으로 표현
- 외부: 초콜릿 버터크림 나무껍질 텍스처 + 세로 홈
- 내부 단면 (상단 visible): 초콜릿 스펀지 + 크림 소용돌이
- 홀리 잎 + 베리 데코 1–2개

**Lv10 — 앙트르메 (미러 글레이즈 케이크)** ← 프레스티지 아이템
- 완벽하게 매끈한 원형 케이크
- 미러 글레이즈: 인디고-퍼플-골드 그라디언트, 갤럭시 또는 마블링 패턴
- 금박 (gold leaf) 파편 산재
- "보석이나 행성 같다"는 느낌 → 거의 비현실적으로 아름다워야 함

**Lv11 — 크로캉부슈** ← 그랑 피날레
- 슈크림 탑, 원 프레임에 꽉 차게 약간 측면 각도로 표현
- 스펀 슈가 (spun caramel) 그물망 실 가시적 표현 (반투명 골드 선)
- 최상단 슈가 플라워 장식 1개
- 가장 공들인 아이템 — 플레이어의 성취 보상

## 4. SFX 스펙

**포맷**: `.ogg` (primary) + `.mp3` (Safari fallback)
**샘플레이트**: 44.1 kHz, Stereo
**공통 톤**: 소형 warm room reverb 통일. 메탈릭/신스 톤 지양.

| ID | 파일명 | 길이 | 트리거 | 설명 |
|---|---|---|---|---|
| SFX-01 | `sfx-drop.ogg` | 0.2–0.4s | 아이템 낙하 | 소프트 "plop" — 슈크림이 카운터에 착지하는 느낌. 짧은 어택, 빠른 디케이. 잔향 없음. |
| SFX-02 | `sfx-merge-sm.ogg` | 0.3–0.5s | Lv 1–4 합체 | 경쾌한 차임 / 스파클 틴클. 2음 상행 톤. 가볍고 상쾌. |
| SFX-03 | `sfx-merge-md.ogg` | 0.4–0.7s | Lv 5–7 합체 | 따뜻한 벨 차임. 3음 상행 아르페지오. 공명 약간 더 풍부. |
| SFX-04 | `sfx-merge-lg.ogg` | 0.6–1.0s | Lv 8–9 합체 | 마림바/레조넌트 벨 히트 + 스파클 테일. 보상감 강조. |
| SFX-05 | `sfx-merge-epic.ogg` | 1.0–1.5s | Lv 10–11 합체 | 풀 팡파르 스팅 — 하프 글리산도 + 따뜻한 금관 코드. 명확한 "achievement" |
| SFX-06 | `sfx-gameover.ogg` | 1.5–2.5s | 게임오버 | 슬픈-귀여운 트롬본 슬라이드 다운 → 마지막 벨 1개. 가혹하지 않게. |
| SFX-07 | `sfx-ui-click.ogg` | 0.05–0.1s | 버튼 클릭 | 드라이한 클릭. 잔향 없음. |

## 5. BGM 스펙

| ID | 파일명 | 길이 | 루프 |
|---|---|---|---|
| BGM-01 | `bgm-game.ogg/.mp3` | 60–120s | Yes |
| BGM-02 | `bgm-gameover.ogg/.mp3` | 15–20s | No (optional) |

### BGM-01 — 메인 게임 루프

| 항목 | 내용 |
|---|---|
| 장르 | French café jazz / light acoustic |
| BPM | 90–105 (여유 있지만 집중감) |
| 악기 | 어쿠스틱 기타, 라이트 피아노, 아코디언(과하지 않게), 브러시드 드럼 or 손뼉 |
| 무드 | 바쁜 파티스리에서 즐겁게 일하는 집중 상태 |
| 루프 | 심리스 루프. 4 or 8-bar 단위 루프 포인트. 루프 시작/끝 샘플 위치를 파일명 또는 메타데이터로 명시 |
| 다이나믹스 | 4-bar 조용한 인트로 → 메인 테마. 급격한 스웰 없음 (플레이 집중 방해 금지) |
| 목표 라우드니스 | LUFS -18 to -16 (SFX 헤드룸 확보) |

### BGM-02 — 게임오버 (optional)

| 항목 | 내용 |
|---|---|
| 길이 | 15–20s, non-loop |
| 무드 | 익살스러운 아쉬움 → 마지막 소절에 소망 상행음 → "다시 해볼게" 유도 |
| 악기 | 솔로 피아노 or 피아노 + 기타 |
