## 1. 게임 개요

**장르**: Suika Game 구조의 낙하 합체 퍼즐
**세계관**: 프렌치 파티스리 — 마카롱이 떨어져 크로캉부슈로 성장하는 성취감이 핵심
**타겟**: 10–30대 여성, 캐주얼 플레이어

### 브랜드 키워드
| 키워드 | 설명 |
|---|---|
| 프렌치 파티스리 | 마카롱, 에클레어, 크로아상 등 파리 제과 아이템 |
| 따뜻하고 달콤함 | 곡선 위주, 부드러운 질감, 차갑거나 날카롭지 않음 |
| 아기자기함 | 귀엽지만 유치하지 않은 수위 |
| 고급스러운 캐주얼 | 동네 파티스리의 분위기 |

### 아트 스타일
| 항목 | 방향 |
|---|---|
| 스타일 | 2D 플랫 일러스트 + 소프트 섀도, 약간의 hand-drawn 질감 |
| 팔레트 | 크림, 카라멜, 로즈 핑크, 초콜릿 브라운, 피스타치오, 베리 퍼플 |
| 레퍼런스 무드 | Neko Atsume × 프렌치 그림책 × 고급 파티스리 쇼케이스 |
| NOT | 3D 렌더, 과도한 chibi, 네온, 사실적 식품 사진 |

## 3. 스프라이트 스펙 — 11종

### 3.1 게임 공간 기준

| 항목 | 값 |
|---|---|
| 게임 해상도 | 480 × 854 px |
| 컨테이너 영역 | 420 × 680 px |
| 컨테이너 좌/우 | x = 30 / x = 450 |
| 컨테이너 상/하 | y = 92 / y = 772 |
| 스프라이트 형태 | 원형(Circle) 물리 바디 기준 |

### 3.2 공통 기술 규칙

```
포맷     PNG-32 (RGBA, 투명 배경)
앵커     Center (0.5, 0.5)
형태     정사각형 PNG — 아트워크는 내접원 안에만 그릴 것 (캔버스의 85–90% 이내)
마스킹   Phaser가 physics radius로 원형 클리핑 처리 → PNG에 별도 원형 크롭 하지 말 것
광원     좌상단 고정 (전 아이템 동일)
아웃라인 흰색 반투명 테두리 2–3px — 겹쳤을 때 개체 구분용
소스     AI 또는 PSD, 1024×1024 이상
네이밍   item-lv01.png … item-lv11.png (제로패딩 2자리)
납품     2× 기준 (retina 대응). 1× fallback은 @1x/ 폴더에 별도 제공
```

## 4. 아이템별 아트 노트

### Lv01 — 마카롱 쁘띠 (Macaron Petit)

| 항목 | 내용 |
|---|---|
| 주 컬러 | 라벤더 퍼플 `#C9B8D4` + 아이보리 크림 필링 |
| 형태 | 정면에서 본 마카롱. 두 쿠키 사이 크림이 살짝 보임. 25° 내려다보기 각도 권장. |
| 디테일 | 파우더 슈가 질감의 매트한 표면. 크림은 달걀 흰자 색의 가는 선. |
| 분위기 | 가장 작고 귀엽고 심플. 복잡한 디테일 금지. |
| 피할 것 | 초콜릿 마카롱, 밝은 원색 금지 |

### Lv02 — 사블레 버터쿠키 (Sablé Butter Cookie)

| 항목 | 내용 |
|---|---|
| 주 컬러 | 버터 골드 `#EBC97A` + 테두리 크러스트 `#C8993E` |
| 형태 | 동그란 쿠키를 약 15도 틸트하여 내려다보는 각도. 중앙에 포크 무늬 또는 꽃/격자 엠보싱 스탬프. |
| 디테일 | 쿠키 표면에 작은 기포 텍스처. 테두리는 살짝 더 어두운 갈색 구워진 느낌. 72px에서도 엠보싱 패턴 식별 가능해야 함. |
| 분위기 | 클래식하고 따뜻한 홈베이킹 느낌 |
| 피할 것 | 초콜릿 칩 추가 금지 (Lv3 이상과 혼동) |

### Lv03 — 마들렌 (Madeleine)

| 항목 | 내용 |
|---|---|
| 주 컬러 | 레몬 버터 옐로우 `#F5D87A` + 구운 면 브라운 `#C8933A` |
| 형태 | 마들렌 정면. 조개껍데기 모양의 릿지(ridge) 무늬가 뚜렷하게 보임. 조개 릿지 탑뷰 중앙 배치. |
| 디테일 | 릿지 사이 그림자로 입체감. 한쪽 면 더 구워진 갈색. 중앙 살짝 부푼 봉우리(bosse). 레몬 제스트 → 옐로그린 테두리 하이라이트. |
| 분위기 | 상징적인 프렌치 파티스리. 중간 난이도의 인지감. |
| 피할 것 | 초콜릿 코팅 버전 금지 (Lv5와 혼동 가능) |

### Lv04 — 카눌레 (Canelé)

| 항목 | 내용 |
|---|---|
| 주 컬러 | 캐러멜 다크 브라운 `#7B4A1E` 외관 + 크림 `#F5E6CC` 내부 단면 |
| 형태 | 원통 형태의 카눌레를 약 20도 각도에서 내려다봄. 윗면 캐러멜라이즈드 크러스트와 세로 홈 뚜렷하게 표현. |
| 디테일 | 외부: 고광택 캐러멜 코팅(광택 하이라이트 포함). 세로 홈(flute) 12개. 내부 단면 아이보리 크림색. |
| 분위기 | 조금 어둡고 고급스럽지만 귀여운 크기. |
| 피할 것 | 너무 평평하게 그리면 원통감이 사라짐. 측면의 홈 표현 필수. |

### Lv05 — 슈 크림 (Chou à la Crème)

| 항목 | 내용 |
|---|---|
| 주 컬러 | 황금 갈색 슈 껍질 `#D4A055` + 크림 화이트 `#FDF6E8` |
| 형태 | 돔 형태 상단 + 카라멜 drizzle 한쪽. 동그란 슈 반죽이 터져서 크림이 가득 찬 상태를 측면에서 봄. |
| 디테일 | 슈 표면 거친 베이크드 텍스처. 하단 봉합선에 크림이 살짝 삐져나온 디테일. 슈거파우더는 흰색 점들로 표현. |
| 분위기 | 통통하고 볼륨감 있는, 손에 쥐고 싶은 느낌 |
| 피할 것 | 초콜릿 글레이즈드 에클레어와 혼동되지 않도록 |

### Lv06 — 크로아상 (Croissant)

| 항목 | 내용 |
|---|---|
| 주 컬러 | 골든 브라운 `#C8832A` + 라이트 레이어 `#EDD48C` |
| 형태 | 클래식 초승달형 크로아상. 원형 경계 안에 자연스럽게 굽은 형태. 정면에서 약간 위에서 내려다보는 앵글. 러스틱한 원형 파티스리, 25° 탑뷰. |
| 디테일 | 페이스트리 레이어(층)가 가로로 촘촘히 보임. 표면 에그워시 광택. 단면의 층층이 쌓인 결 표현. 가장자리 팁은 더 어두운 브라운. |
| 분위기 | 가장 아이코닉한 파티스리. 누구나 바로 알아볼 수 있어야 함. |
| 피할 것 | 너무 직선적으로 그리면 안 됨. 크루아상 특유의 부드러운 굽은 형태 유지. |

### Lv07 — 타르트 오 프뤼 (Tarte aux Fruits) ← 첫 번째 "와" 포인트

| 항목 | 내용 |
|---|---|
| 주 컬러 | 밀 타르트 껍질 `#D4A055`, 커스터드 크림 `#FBE99A`, 딸기 `#E05050`, 블루베리 `#5A5CB4`, 키위 `#6DB35A` |
| 형태 | 원형 타르트를 정면에서 45도 내려다봄. 원형 경계와 타르트 원형이 자연스럽게 일치. |
| 디테일 | 플루티드(주름) 타르트 테두리. 노란 커스터드 크림 위에 과일 5–7종 방사형 배치. 딸기 반쪽 3–4개, 블루베리 4–5개, 키위 1–2슬라이스 + 라즈베리 조합. 과일 위 젤리 글레이즈 반사광 필수. 광택 나파주(코팅) 반짝임 표현. |
| 분위기 | 색깔이 많아서 화려함. "먹음직스럽다" 반응 유도. |
| 피할 것 | 과일이 너무 사실적이면 안 됨. 귀여운 벡터 일러스트 스타일 유지. |

### Lv08 — 오페라 케이크 (Opéra)

| 항목 | 내용 |
|---|---|
| 주 컬러 | 초콜릿 글레이즈 `#2C1A0E`, 커피 크림 `#7B4E2A`, 골드 장식 `#D4A937` |
| 형태 | 정사각형에 가까운 케이크 슬라이스를 약간 측면에서 본 모습. 원형 경계에 자연스럽게 배치. |
| 디테일 | 층(layer)이 3–4개 보이는 단면: 초콜릿 글레이즈 → 커피 크림 → 제누아즈 스펀지 → 반복. 윗면은 매끄러운 다크 초콜릿 글레이즈에 황금색 "Opéra" 글자 데코(작게, 장식용). 한쪽 모서리는 포크로 잘린 단면이 보임. |
| 분위기 | 어둡고 고급스럽고 진지함. 이 레벨을 만들면 숙련자임을 인식. |
| 피할 것 | 너무 어두워서 Lv11 케이크와 구분이 안 되면 안 됨. 층(레이어) 표현이 핵심. |

### Lv09 — 샤를로트 케이크 (Charlotte Royale) ← 비주얼 하이라이트

| 항목 | 내용 |
|---|---|
| 주 컬러 | 딸기 레드 `#E05050`, 핑크 크림 `#F7B8B8`, 아이보리 `#FDF6E8` |
| 형태 | 반구형(돔 형) 케이크를 25° 탑뷰에서 내려다봄. 원형 경계와 케이크 원형이 일치. |
| 디테일 | 위에서 보면 소용돌이 형태의 딸기 롤케이크 슬라이스들이 원형으로 배열됨 (달팽이 소용돌이 패턴). 각 롤케이크 슬라이스는 딸기 붉은색 + 크림 흰색의 나선형. 중앙에 딸기 한 개. SNS에 올리고 싶을 만큼 아름다워야 함. |
| 분위기 | 화려하고 독특한 패턴. 한눈에 "다른 케이크들과 다르다"는 것을 알 수 있어야 함. |
| 피할 것 | 패턴이 너무 복잡하면 작은 화면에서 뭉개짐. 소용돌이 패턴을 심플하게 유지. |

### Lv10 — 밀 푀유 (Mille-Feuille) ← 프레스티지 아이템

| 항목 | 내용 |
|---|---|
| 주 컬러 | 퍼프 레이어 크림 `#EDD48C`, 커스터드 `#FBE99A`, 아이싱 화이트 `#FDF9F4`, 초콜릿 장식선 `#5C3317` |
| 형태 | 직사각형 케이크를 45도 측면에서 봄. 원형 경계 안에 자연스럽게 배치. |
| 디테일 | 퍼프 페이스트리 층이 3겹 뚜렷하게 보임. 맨 위는 흰 폰당 아이싱. 아이싱 위에 초콜릿 라인이 가로로 그어지고 이쑤시개로 지그재그 긁은 패턴(전통 마블링). 층 사이에 노란 커스터드와 크림이 가득. 지그재그 선은 3–5개로 제한. |
| 분위기 | 클래식하고 우아함. 이 레벨을 달성하면 진짜 숙련자. |
| 피할 것 | 마블링 패턴이 너무 복잡하면 인식이 어려움. |

### Lv11 — 크로캉부슈 (Croquembouche) ⭐ 최고 레벨

| 항목 | 내용 |
|---|---|
| 주 컬러 | 카라멜 골드 `#D4A937`, 슈 크림 `#D4A055`, 슈거 스레드 `#FFE9A0`, 아이보리 크림 `#FDF6E8` |
| 형태 | 원뿔 형태로 쌓인 슈 피라미드를 원 프레임에 꽉 차게 약간 측면 각도로 표현. |
| 디테일 | 크고 작은 슈 볼들이 피라미드 형태로 쌓임. 전체를 감싸는 반투명 골드 스펀 슈가(caramel thread) 그물망 실 가시적 표현. 맨 위에 슈가 플라워 장식 1개. 전체적으로 황금빛 광채. |
| 분위기 | 게임 최고 레벨. 축제적이고 화려하고 강렬해야 함. 플레이어가 성취감을 느껴야 함. |
| 특별 요청 | 반드시 다른 10개 레벨과 확실히 구분되어야 함. 11개 중 가장 많은 시간을 투자할 것. |

## 6. SFX 스펙

**공통 사양**: WebAudio 호환 `.ogg` (primary) + `.mp3` (Safari fallback)
샘플레이트: 44,100 Hz / 채널: 모노 / 루프: 없음 / 마스터 레벨: -6 dBFS 기준
톤: warm room reverb 통일. 메탈릭/신스 톤 지양.

| 파일명 | 트리거 | 길이 | 설명 |
|---|---|---|---|
| `sfx-drop.ogg` | 아이템 낙하 시 | 0.2–0.4s | 가볍고 경쾌한 "뽁" 소리. 유리컵에 마카롱이 살짝 닿는 느낌. 짧은 어택, 빠른 디케이. 잔향 없음. |
| `sfx-land.ogg` | 아이템 착지 시 | 0.2–0.3s | drop보다 약간 더 묵직한 소리. "통통" 느낌. 아이템 크기에 따라 피치를 달리하면 이상적. |
| `sfx-merge-low.ogg` | Lv1–5 합체 | 0.4–0.6s | 달콤하고 경쾌한 "짠!" 소리. 설탕 결정이 부딪히는 느낌. 반짝이는 고음역. |
| `sfx-merge-high.ogg` | Lv6–9 합체 | 0.5–0.8s | 따뜻한 벨 차임. 더 풍부하고 화음이 있는 소리. "두둥!" + 반짝임. 성취감 있는 화음. |
| `sfx-merge-epic.ogg` | Lv10–11 합체 | 0.8–1.2s | 팡파르 느낌의 짧은 악구. "브라보!" 느낌. 하프 글리산도 + 따뜻한 금관 코드. 게임 내 가장 화려한 SFX. |
| `sfx-gameover.ogg` | 게임오버 확정 | 0.5–1.0s | 아쉽지만 귀엽고 너무 슬프지 않은 소리. 슬픈-귀여운 트롬본 슬라이드 다운 → 마지막 벨 1개. |
| `sfx-ui-click.ogg` | UI 버튼 클릭 | 0.1–0.2s | 아주 가볍고 짧은 클릭 소리. 드라이한 클릭. 잔향 없음. |

> `sfx-land` 피치 변동 구현 여부: MVP에서 단일 사운드 처리 가능. 구현 시 Phaser `WebAudioSound.setRate()`로 레벨 반지름 기준 스케일링.

## 9. 엔지니어링 제약사항

| 항목 | 내용 |
|---|---|
| Phaser 로드 경로 | `public/assets/` → URL: `/assets/sprites/item-lv01.png` |
| 원형 클리핑 | PNG에 원형 크롭 하지 말 것. Phaser가 physics radius 기준으로 자동 클리핑 |
| 스케일링 | 엔진이 `radius × 2`로 자동 스케일. 2× PNG = retina 선명 |
| 애니메이션 | MVP는 정적 스프라이트. 스프라이트시트 불필요 (향후 idle bounce 추가 예정) |
| 오디오 API | Web Audio API. SFX < 0.5s pre-decode, BGM 스트리밍. OGG 우선, MP3 fallback. |
| 파일 사이즈 예산 | 스프라이트 전체 < 3 MB / BGM < 5 MB per track / SFX 전체 < 200 KB |
| 9-slice UI | `btn-restart.png`, `hud-panel-bg.png` → 코너 12px 기준으로 설계 |

## 10. 자체 검수 체크리스트

### 스프라이트
- [ ] 11개 아이템 모두 원형 경계 안에 들어옴
- [ ] 72px (Lv1) 크기로 렌더링해도 아이템 구분 가능
- [ ] 1180px (Lv11) 크기로 확대해도 깨지지 않음 (벡터 기반)
- [ ] 배경이 완전 투명 (체커보드 배경으로 확인)
- [ ] 11개를 한 화면에 나란히 놓았을 때 레벨 순서가 직관적으로 보임

### HUD / 컨테이너
- [ ] 컨테이너 배경이 스프라이트를 가리지 않음
- [ ] 점수 숫자 8자리(99,999,999)를 표시해도 잘림 없음
- [ ] 게임오버 오버레이가 가독성을 해치지 않음

### SFX / BGM
- [ ] 각 SFX 파일 무음 구간이 앞뒤로 0.05초 이상 없음
- [ ] BGM 루프 시 끊김 없음 (오디오 에디터에서 파형 확인)
- [ ] 전체 SFX 레벨이 -6 dBFS 내외
